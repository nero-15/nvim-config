# 08 画面・タブ・ファイル — 迷子にならない

> 所要 20 分。分割は tmux でも Ghostty でもなく、**全部 Neovim で**やる。

## 3 つの単位

```
タブ（作業の文脈。worktree ごとに 1 つ）
 └─ ウィンドウ（画面の分割）
     └─ バッファ（開いているファイル）
```

- **バッファ** = 開いたファイル。画面に見えていなくても裏で開いている。
- **ウィンドウ** = 画面の区切り。同じバッファを 2 つのウィンドウで見ることもできる。
- **タブ** = ウィンドウの並びのセット。この環境では**作業の文脈（worktree）**として使う。タブごとに作業ディレクトリが違う。

## ウィンドウ（分割）

| キー | 動作 |
|------|------|
| `<Space>\|` / `<Space>-` | 右に / 下に分割 |
| `Ctrl-h/j/k/l` | 左 / 下 / 上 / 右のウィンドウへ（Claude のターミナルからも同じ） |
| `Ctrl-矢印` | ウィンドウの大きさを変える |
| `<Space>tZ` | 今のウィンドウを一時的に最大化（もう一度で戻る） |
| `:q` | ウィンドウを閉じる |

- [ ] `<Space>|` で右に分割し、`Ctrl-l` と `Ctrl-h` で行き来した
- [ ] `<Space>-` で下にも分割し、`Ctrl-j` / `Ctrl-k` で行き来した
- [ ] `<Space>tZ` で最大化し、もう一度押して戻した。余分なウィンドウを `:q` で閉じた

## バッファ

| キー | 動作 |
|------|------|
| `Shift-h` / `Shift-l` | 前 / 次のバッファ |
| `<Space>fb` | バッファの一覧 |
| `<Space>bd` | バッファを閉じる（ウィンドウは残る） |
| `<Space>bo` | 今のバッファ以外を閉じる |

## よく使うファイルに瞬間移動（harpoon）

| キー | 動作 |
|------|------|
| `<Space>ha` | 今のファイルを登録 |
| `<Space>hh` | 登録したファイルの一覧（並べ替えもできる） |
| `<Space>1`〜`4` | 1〜4 番目のファイルへ |

- [ ] ファイルを 2 つ `<Space>ha` で登録し、`<Space>1` と `<Space>2` で行き来した

## タブ = 作業の文脈

| キー | 動作 |
|------|------|
| `]<Tab>` / `[<Tab>` | 次 / 前のタブ |
| `<Space><Tab>d` | タブを閉じる |
| `<Space>gw` | worktree を選んで新しいタブで開く（レッスン 09） |

タブが 2 つ以上になると、画面の上にタブの一覧が出ます。🤖 付きのタブはエージェントの worktree です。

- [ ] `:tabnew` でタブを作り、`]<Tab>` で行き来して、`<Space><Tab>d` で閉じた

## ファイルを探す・開く

| キー | 動作 |
|------|------|
| `<Space><Space>` | 賢いファイル検索（最近開いた順も考慮） |
| `<Space>fr` | このプロジェクトで最近開いたファイル |
| `<Space>e` | ファイルツリー |
| `-` | 親ディレクトリ（oil） |

## 卒業チェック

- [ ] 「バッファ・ウィンドウ・タブ」の違いを説明できる
