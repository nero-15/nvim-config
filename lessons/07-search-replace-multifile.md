# 07 検索・置換・複数ファイル — プロジェクト全体を一気に直す

> 所要 30 分。この設定リポジトリ（`~/devel/nvim-config`）で開いてやると練習しやすい。

## ファイルの中

| キー | 動作 |
|------|------|
| `/単語` → `<Enter>` | 下へ検索。`n` で次、`N` で前 |
| `*` | カーソル下の単語を検索 |
| `:%s/古/新/g` | ファイル全体を置換（打っている間に結果がライブで見える） |
| `<Space>rs` | カーソル下の単語の `:s` を組み立てる |
| `<Esc>` | 検索のハイライトを消す |

```text
TODO: 仕様を書く
TODO: テストを書く
TODO: レビューする
```

- [ ] `/TODO` で検索し、`n` で順に巡った
- [ ] `:%s/TODO/DONE/g` と打つ途中で、置換結果がライブで表示されるのを見た（確定させてもよい）

## プロジェクト全体を探す

| キー | 動作 |
|------|------|
| `<Space><Space>` | ファイルを賢く探す |
| `<Space>fg` | 全ファイルを grep |
| `<Space>fs` | カーソル下の単語で grep |
| `<Space>fR` | 直前の検索画面をもう一度 |

ピッカーの中では: 文字を打つと絞り込み、`Ctrl-j` / `Ctrl-k` で上下、`<Enter>` で開く。

- [ ] `<Space>fg` で `Snacks` を検索し、結果の 1 つを開いた
- [ ] `<Space>fR` で同じ検索に戻った

## quickfix — 「場所の一覧」を巡る

grep の結果や verify のエラーは **quickfix**（場所の一覧）に入ります。

| キー | 動作 |
|------|------|
| ピッカーで `Ctrl-q` | 結果を全部 quickfix に送る |
| `]q` / `[q` | 次 / 前の場所へ |
| `<Space>xq` | quickfix を開く / 閉じる |

**quickfix は編集できます**: 開いた一覧の行を書き換えて `:w` すると、各ファイルに反映されます。

- [ ] `<Space>fg` で `desc =` を検索し、`Ctrl-q` で quickfix に送った
- [ ] `]q` を何回か押して場所を巡った
- [ ] `<Space>xq` で一覧を開き、`q` で閉じた（編集して `:w` は、試すなら後で `u` と `git checkout` で戻す）

## プロジェクト全体の置換（grug-far）

`<Space>rr` で検索・置換の画面が開きます。上の欄に「検索」「置換」を打つと、全ファイルの変更後の姿がその場で見えます。

- [ ] `<Space>rr` を開き、検索欄に `vim.notify` と打って、どのファイルに何件あるか見た（置換はしない）

## ファイルをバッファとして編集（oil）

`-` を押すと、今のファイルがあるディレクトリが**普通のテキストとして**開きます。

| 操作 | 結果（`:w` で確定） |
|------|------------------|
| 行を書き換える | ファイル名の変更 |
| `dd` | 削除 |
| `yy` → 別のディレクトリで `p` | コピー |
| 新しい行を書く | ファイルを作る（末尾に `/` でディレクトリ） |

- [ ] `-` でディレクトリを開き、`<Enter>` でファイルを開き、もう一度 `-` で戻った
- [ ] oil の中で新しい行に `practice.txt` と書いて `:w` し、作られたのを確認してから `dd` → `:w` で消した

## マーク — 場所に付箋を貼る

| キー | 動作 |
|------|------|
| `ma` | この場所にマーク `a` |
| `'a` | マーク `a` の行へ戻る |
| `mA`（大文字） | ファイルをまたぐマーク |
| `<Space>fm` | マークの一覧 |

- [ ] このファイルで `mA` を付け、別のファイルに移ってから `'A` で戻ってきた
