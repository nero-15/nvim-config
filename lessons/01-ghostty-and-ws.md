# 01 Ghostty と ws — 端末アプリで迷わない

> 所要 15 分。Ghostty の中でこのファイルを開いてやってください。

## 全体像

```
Ghostty（端末アプリ）
 └─ tmux（裏方。プロジェクトごとのセッションを保つだけ）
     └─ Neovim（ここがすべての作業場所。分割・Claude・ターミナルもここ）
```

- **Ghostty**: Terminal.app の代わりの端末アプリ。速く、画像（Mermaid の図）を表示できる。
- **tmux**: 見えない裏方。端末を閉じても Neovim と Claude を生かしておく。**操作はほぼ覚えなくてよい。**
- **Neovim**: 画面の分割もターミナルも Claude も、全部この中でやる。

Terminal.app も今までどおり使えます。`ws` はどちらから実行しても、実行した側のアプリで開きます。

## Ghostty で覚えるキー（Cmd = ⌘）

| キー | 動作 |
|------|------|
| `Cmd-n` | 新しいウィンドウ |
| `Cmd-t` | 新しいタブ |
| `Cmd-w` | 閉じる |
| `Cmd-1`〜`9` | タブへ移動 |
| `Cmd-=` / `Cmd--` / `Cmd-0` | 文字を大きく / 小さく / 元に戻す |
| `Cmd-Enter` | フルスクリーン |
| `Cmd-f` | 画面内を検索 |
| `Cmd-Shift-p` | コマンドパレット（キーを忘れたらここ） |
| `Cmd-,` | 設定ファイルを開く |
| `Cmd-Shift-,` | 設定を再読み込み |

Ghostty 自身の分割（`Cmd-d`）は**使いません**。分割は Neovim でやります（レッスン 08）。

## ws — プロジェクトを開く

シェル（Neovim の外）で `ws` と打つと、`~/devel` のプロジェクトを fzf で選べます。

- 選ぶと新しいウィンドウで tmux + Neovim が起動し、ダッシュボードが出ます。
- すでに開いているプロジェクトなら、そのセッションに戻ります（作業の続きから）。
- プロジェクトごとに tmux のステータスバーの色が変わります。
- `ws ~/devel/nvim-config` のようにパスを渡すと、選ぶ手間を省けます。

## tmux で覚えるのは 2 つだけ

| キー | 動作 |
|------|------|
| `Ctrl-b` → `d` | tmux から抜ける（Neovim も Claude も裏で生き続ける） |
| `Ctrl-b` → `s` | セッション一覧から選んで切り替え |

抜けたセッションには、もう一度 `ws` で同じプロジェクトを選べば戻れます。

## 練習

- [ ] Ghostty で `Cmd-t` を押してタブを開き、`Cmd-w` で閉じた
- [ ] `Cmd-=` で文字を大きくし、`Cmd-0` で戻した
- [ ] `Cmd-Shift-p` でコマンドパレットを開き、`Esc` で閉じた
- [ ] 別のタブで `ws` を実行し、プロジェクトを 1 つ開いた
- [ ] 開いたプロジェクトで `Ctrl-b` → `d` で抜け、`ws` でもう一度同じプロジェクトを選んで戻れた
- [ ] Terminal.app でも `ws` を実行し、Terminal.app のウィンドウで開くことを確かめた
