# 05 繰り返す — 同じ作業は 1 回で済ませる

> 所要 30 分。vimmer と初心者の差が一番出るところ。

## `.`（ドット）— 直前の変更を繰り返す

**Vim で一番強いキー。** 「変更」を 1 回やったら、あとは `.` で同じ変更を繰り返せます。

コツは、**繰り返しやすい形で 1 回目を行う**こと。
例: 行末に `;` を足すなら、`$a;` より `A;` のほうが 1 つの変更として `.` で繰り返しやすい。

### 練習 1: 行末に ; を足す

```js
const a = 1
const b = 2
const c = 3
const d = 4
```

- [ ] 1 行目で `A;` → `jk`。2 行目以降は `j.` を繰り返して全行に `;` を足した

## `*` + `cgn` + `.` — 見ながら置換

1. 変えたい単語の上で `*`（同じ単語を検索）
2. `cgn` で次の一致を書き換え → `jk`
3. `.` を押すたびに、次の一致が同じように書き換わる（飛ばしたいときは `n`）

### 練習 2: user を member に

```ts
const user = getUser(id);
if (!user) throw new Error("user not found");
logger.info({ user });
return user;
```

- [ ] 最初の `user` の上で `*` → `cgn` → `member` → `jk` → `.` を繰り返し、`getUser` は変えずに全部置換した

## マクロ — 操作をまるごと記録して再生

| キー | 動作 |
|------|------|
| `qa` | レジスタ `a` に記録開始（ステータスラインに `REC @a`） |
| `q` | 記録終了 |
| `@a` | 再生 |
| `@@` | 直前のマクロをもう一度 |
| `10@a` | 10 回再生 |

コツ: 記録の最後に**次の行へ移動する**（`j` や `0j`）と、連続再生できます。

### 練習 3: CSV を Markdown の表にする

```text
name,role,team
Astra,Planner,api
Sol,Maker,admin
Terra,Checker,infra
```

1 行目の先頭にカーソルを置いて、次の操作を記録します:
`qa` → `I| ` → `jk` → `:s/,/ | /g` と打って `<Enter>` → `A |` → `jk` → `j0` → `q`

- [ ] 1 行目でマクロを記録した
- [ ] `3@a` で残りの 3 行にも適用した
- [ ] 2 行目の下に `|---|---|---|` を足して、Markdown の表の形にした

## `:norm` — 選択した行に Normal モードの操作をまとめて

`V` で行を選んで `:norm A;` と打つと、選んだ全行で `A;` を実行します。

```js
const x = 1
const y = 2
const z = 3
```

- [ ] 3 行を `V` で選び、`:norm A;` で全行に `;` を足した
- [ ] 同じ 3 行を選び、`:norm Iexport ` で全行の先頭に `export ` を足した
