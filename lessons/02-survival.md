# 02 生き残る — 開く・書く・保存・終了・やり直し

> 所要 20 分。ここが確実になれば、あとは何をしても戻ってこられる。

## モードは 4 つだけ

| モード | 何をする | 入り方 | 出方 |
|--------|----------|--------|------|
| **Normal** | 移動と操作（ここが基本の居場所） | `<Esc>` か `jk` | — |
| **Insert** | 文字を打つ | `i` `a` `o` など | `jk`（または `<Esc>`） |
| **Visual** | 範囲を選ぶ | `v`（文字） `V`（行） `Ctrl-v`（矩形） | `<Esc>` |
| **Command** | `:` で始まる命令 | `:` | `<Enter>` で実行、`<Esc>` で取り消し |

**迷ったら `<Esc>`。** Normal モードに戻れば安全です。

## 覚えるキー

| キー | 動作 |
|------|------|
| `i` / `a` | カーソルの前 / 後ろから入力 |
| `I` / `A` | 行頭 / 行末から入力 |
| `o` / `O` | 下 / 上に新しい行を作って入力 |
| `jk` | Insert モードを抜ける（この環境の設定） |
| `x` | 1 文字削除 |
| `dd` | 1 行削除（切り取り） |
| `yy` | 1 行コピー |
| `p` / `P` | 下 / 上に貼り付け |
| `u` / `Ctrl-r` | 取り消し / やり直し |
| `:w` または `<Space>w` | 保存 |
| `:q` / `:qa` | 閉じる / 全部閉じて終了 |
| `h` `j` `k` `l` | 左 下 上 右（今は使ってよい。レッスン 04 で卒業する） |

## 練習

下の文章を、指示どおりに直してください（Normal モードで操作）。

```text
1. この行の末尾に「です」を足す（A で行末へ → 入力 → jk）
2. この行の先頭に「★」を足す（I で行頭へ）
3. この行を丸ごと消す（dd）
4. この行の下に新しい行を作って「追加した」と書く（o）
5. この行をコピーして、すぐ下に貼る（yy → p）
6. xこxのx行xのx「x」xをx全x部x消xすx（x を何回か）
```

- [ ] 1〜6 をやった
- [ ] 間違えたときに `u` で戻せた。`Ctrl-r` でやり直せた
- [ ] `<Space>w` で保存した（ステータスラインの `●` が消える）

## Space を押して待つ

`<Space>` を押して**何も押さずに待つ**と、次に押せるキーの一覧が出ます（which-key）。
キーを忘れたら、とりあえず `<Space>` を押して待つ。これだけで、この環境のほぼ全部に辿り着けます。

- [ ] `<Space>` を押して待ち、一覧が出た。`<Esc>` で閉じた
- [ ] `<Space>` → `f` と押して待ち、「Find」の中身を見た

## ヘルプを引く

- `:help 単語` で公式ヘルプを引けます（例: `:help dd`）。`q` で閉じます。
- `<Space>H` はこの環境のチートシート（`:help nvim-config`）です。

- [ ] `:help u` を開いて `q` で閉じた
- [ ] `<Space>H` でチートシートを開いた
