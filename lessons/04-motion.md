# 04 跳ぶ — jjjj をやめる

> 所要 30 分。この環境では hardtime が `jjjj` のような連打にヒントを出します。

## 原則

**同じキーを 3 回以上押したら、もっと良い方法がある。**

## 行の中を跳ぶ

| キー | 動作 |
|------|------|
| `w` / `b` / `e` | 次の単語の頭 / 前の単語の頭 / 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 最初の文字 / 行末 |
| `f{文字}` | その文字まで跳ぶ（`F` は左へ） |
| `t{文字}` | その文字の手前まで（`T` は左へ） |
| `;` / `,` | 直前の `f` `t` を繰り返す / 逆向きに |

`t` は動詞と組み合わせると強力です: `dt)` = `)` の手前まで削除。

## 画面の中を跳ぶ

| キー | 動作 |
|------|------|
| `5j` / `12k` | 相対行番号を見て、その行数だけ上下に（左の数字を使う） |
| `{` / `}` | 段落の前 / 次へ |
| `Ctrl-d` / `Ctrl-u` | 半ページ下 / 上 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `%` | 対応する括弧へ |
| **`s`** | **flash**: 見えている場所へ 2〜3 キーで跳ぶ（下で練習） |

### flash の使い方

1. `s` を押す
2. 跳びたい場所の文字を 1〜2 文字打つ
3. 候補にラベル（色付きの文字）が出るので、そのラベルを押す

`S` を押すと、構文の単位（関数や if）で選べます。

## コードの中を跳ぶ

| キー | 動作 |
|------|------|
| `gd` | 定義へ |
| `grr` | 参照の一覧 |
| `]m` / `[m` | 次 / 前の関数 |
| `]d` / `[d` | 次 / 前のエラー・警告 |
| `]h` / `[h` | 次 / 前の git の変更 |
| `Ctrl-o` / `Ctrl-i` | 跳ぶ前に戻る / 進む（ブラウザの戻る・進む） |
