# 03 文法 — 「動詞 + 対象」で考える

> 所要 30 分。**Vim で一番大事なレッスン。**ここがわかると、覚えることが一気に減る。

## 考え方

Vim のキーは、単語帳のように丸暗記するものではありません。**文法**です。

```
動詞 + 対象
 d   +  iw     → 単語（の中）を削除
 c   +  i"     → " の中を書き換え
 y   +  ap     → 段落ごとコピー
```

動詞を 5 つ、対象を 10 個覚えれば、5 × 10 = 50 通りの操作が**覚えずに**使えます。

### 動詞

| 動詞 | 意味 |
|------|------|
| `d` | 削除（切り取り） |
| `c` | 削除して Insert モードへ（書き換え） |
| `y` | コピー |
| `v` | 選択 |
| `>` `<` | インデント |
| `gc` | コメントの付け外し |
| `gu` `gU` | 小文字 / 大文字 |

### 対象（テキストオブジェクト）

`i` は **inner（中身だけ）**、`a` は **around（周りごと）**。

| 対象 | 意味 |
|------|------|
| `iw` / `aw` | 単語 |
| `i"` / `a"`（`iq` はどの引用符でも） | 引用符 |
| `i(` / `a(`（`ib` はどの括弧でも） | 括弧 |
| `it` / `at` | HTML タグ |
| `ip` / `ap` | 段落 |
| `if` / `af` | 関数 |
| `ia` / `aa` | 引数 |
| `ie` | camelCase / snake_case の 1 語 |

## 練習 1: 引用符と括弧

カーソルを `"` の中のどこかに置いてから操作します。

```js
const message = "こんにちは世界";
const total = sum(price, tax, shipping);
const tag = "<span>古い文字</span>";
```

- [ ] 1 行目: `ci"` で「こんにちは世界」を「さようなら」に書き換えた
- [ ] 2 行目: `ci(` で括弧の中を `a, b` に書き換えた
- [ ] 2 行目: `tax` の上で `daa` を押し、引数ごと（カンマも）消えるのを見た
- [ ] 3 行目: `<span>` の中で `cit` を押してタグの中身だけを書き換えた

## 練習 2: 関数と段落

```ts
function calculateShippingFee(weight: number) {
  const base = 500;
  return base + weight * 10;
}

これは段落です。
2 行目も同じ段落です。
```

- [ ] 関数の中で `yif` を押して中身をコピーし、`p` で貼った（確認したら `u`）
- [ ] 関数の中で `vaf` を押し、関数全体が選択されるのを見た（`<Esc>` で解除）
- [ ] `calculateShippingFee` の `Shipping` の上で `cie` を押し、`Delivery` に書き換えた
- [ ] 段落の上で `dap` を押して段落ごと消し、`u` で戻した

## 練習 3: 「次の」対象

カーソルが括弧の**外**にあっても、`n`（next）を挟めば次の括弧を狙えます。

```js
console.log("カーソルを行頭に置いたまま操作する");
```

- [ ] 行頭（`0`）にカーソルを置いたまま `cin"` を押し、" の中を書き換えた
- [ ] 同じく行頭から `yin(` を押し、括弧の中をコピーした

## 数を付ける

`3dd`（3 行削除）、`2dw`（2 単語削除）のように、**動詞の前に数**を付けられます。

- [ ] 下の 5 行のうち、上の 3 行を `3dd` で一度に消した

```text
消す 1
消す 2
消す 3
残す 4
残す 5
```
