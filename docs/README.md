# docs — nvim-config の設計と運用

一つの文書は一つの問いに答える。同じ決まりを二か所に書かず、他の文書からはリンクする。
このディレクトリは Neovim の設定として読まれない（`:help nvim-config` は単数形の `doc/`）。

## 書く場所

迷ったらこの表で決める。該当する文書が無い内容は、まず既存の文書に節を足せないかを考える。

| 書きたいこと | 場所 | 書かないこと |
|---|---|---|
| 新しい要求・受け入れ条件 | 02 | 実装の手順 |
| 役割・受け渡し・ハーネスの決まり | 01 | キーの一覧（06 へ） |
| ファイルの置き場所・コマンドと実装の対応 | 03 | 使い方 |
| 検査の追加・合否の基準・未確認の範囲 | 04 | 進捗 |
| 覚える順番に並べたキー | 05（which-key と `doc/nvim-config.txt` にも載せる） | 運用上の注意（06 へ） |
| 使い方・運用上の注意・再起動の単位 | 06 | 採用理由（ADR へ） |
| 採用・廃止・大きな方針変更の理由 | [adr/](adr/) | 現行の手順（01・06 へ） |
| 進捗・未確認・次の一手 | tasks（短く保つ。経緯は Git 履歴） | 完了した作業の記録 |
| 調査・レビューなど、ある時点の記録 | [archive/](archive/)（ファイル名に日付） | 現行の決まり |
| 概念を学ぶ教材 | [guides/](guides/) | 現行の手順 |

`make doc-links-check`（V-9）が、ファイルリンク切れと、この索引から辿れない文書を検出する。節アンカーと外部 URL は検査しない。
