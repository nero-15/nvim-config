# ADR-0001: DNA と仕様を docs/ に置き、設定もループで育てる

- 状態: **Accepted**
- 日付: 2026-09-27

## 背景
nvim-config は README とコード内のコメントだけで運用してきた。開発のスタイルが自律エージェント + ループエンジニアリングに移ったため、
「なぜこの設定なのか」がエージェントにも将来の自分にも伝わる形で残っていない。

## 決定
- `docs/` に DNA（00）・開発ループ（01）・要求（02）・構成（03）・検証（04）・学習（05）・ADR・tasks を置く。
- リポジトリ直下に `CLAUDE.md` / `AGENTS.md` を置き、エージェントの入口にする。
- 他プロジェクト（bukatsu-one 系）と同じ形式（要求 ID、ADR、機械判定の停止条件、tasks.md による外部メモリ）に揃える。

## 影響
- Neovim の動作には影響しない（`docs/` は runtimepath 上の特殊ディレクトリではない）。
- 設定を変えるときは要求 ID と ADR を更新する手間が増える。そのぶん、判断の理由を失わない。
